libsortition

Builds of the WebAssembly binding and the demo. Each folder holds sortition.js, persist.js, sortition.wasm, the type definitions, the licenses and a manifest.json with the SHA-384 hash of every file.

For a draw that others must trust, use a versioned folder (for example /v0.1.0/), not latest or next: a versioned folder never changes, and you can check its files against the manifest.

import { load } from "https://small-gear-lab.github.io/libsortition/v0.1.1/sortition.js";
const sortition = await load();
